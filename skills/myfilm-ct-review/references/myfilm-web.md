# MyFilm 网页调阅与导出

只需拿原始 CT 文件时，优先用 [独立脚本](myfilm-automation.md)。本页用于手动阅片、网页标注或页面变化时核对原站入口。

在电脑端的授权共享页面实测。不同医院、端型、权限和版本可改变入口。先观察现有标签，不枚举其他标签、凭据或浏览历史。当前页面若需要验证，在原站可见表单输入本次用户授权的分享码。不要把 HTML、完整 DOM 或开发者日志直接回显。仅提取控件名称和技术计数。

## 调阅和选片

1. 电子报告单页的 **查看影像** 打开影像查看器。PC 版本实测嵌入 `iframe.image-frame`。用浏览器提供的 frame locator；不要从 `iframe` URL 重放授权。某些表单按钮中间含空格，例如 “确 定”。等待控件状态后再操作。
2. 底部／侧边 **序列** 缩略图区列出系列。每张缩略图的张数对应各自序列，旁边相邻数字可能是序列号。不要读整块父节点误配计数。待缩略图载入，确认部位、序列号、层数和类型。如果单击未切换，双击目标缩略图并核对当前叠加层数、层厚、序列说明或第一张有效影像。定位像、截图与重建图不能假定为完整轴向 CT。多序列同张数时用描述和标识进一步区分。
3. 实测 PC 结构中 toolbar `.button-name`、序列 `.series-list-item`、影像 `canvas.cornerstone-canvas` 可辅助定位。优先通过可见文本和当前状态缩小范围。类选择器是版本提示，用前现场重查。不要按第三个按钮或固定屏幕坐标盲点。

|---|---|---|
| 序列布局 | 1×1、1×2、2×1、2×2、2×3、自定义 | 先单窗核对序列，再并排比较。同屏不等于同一空间位置；核、方位和层面对齐后才比较。 |
| 序列导航 | 前／后一屏、前／后一序列、恢复初始状态 | 序列内逐层看用滚轮或层滑块。记录起止与漏看的区段。 |

| 窗宽窗位 | W/L、预设肺 F1／骨 F2／肝 F3／软组织 F4／脑 F5／头骨 F6；工具菜单可设置明确值 | 先预设定位，再记实际 W/W 和 W/L 数值。切换显示不改变源体素。 |

| DICOM 信息、全屏、帮助 | DICOM 信息对话框已打开；其余为可见工具 | 对话框只私下核验序列几何字段，不导出完整标签表。 |

## 三维与深度用法

- 在二维选定多层数组后点击 **三维**。等待载入，进入后的工具栏变为 **二维、布局、中心点、W/L、平移、缩放、复位、标注、包围盒、显示设置、全屏**。布局入口曾见 **MPR、VR**。必须确认选中的是目标序列，看到位于三面同一位置的结构，才能声称 MPR 可用。缩略图出现或工具栏切换本身不足以判断体数据加载成功。
- MPR 中普通参考线用于平移切面，参考线上离中心一段距离的小圆柄用于斜位旋转，方形柄或相应设置改变显示投影厚度。先在两正交切面定位，再将第三面转到目标结构，观察另外面是否联动。复位后核对方向。按钮或柄飘移时先退出标注、缩小缩放再定位，避免连续误拖。
- 定量优先薄切、原始层和可追踪的对应端点；记录厚度及是否用了 MIP。MIP 厚层能辅助找骨性结构，易叠加不同深度，不能把投影重合当真实接触。VR／包围盒用于总览和定位；阈值、裁切、显示伪影都会改变表面外观。历史实例中实际验证了长度、斜位和薄 MIP；其他投影模式和高级标注依版本逐项验证。
- 平台的内部 JS 模块、缓存和私有请求不属于稳定接口。无需从内部对象寻找端点，可转本地 DICOM 以患者坐标复算并保存重切参数。

## 导出与验收

1. 回二维，选定且加载目标序列。右键影像画面，点击 **导出此序列dicom图像**。优先使用浏览器正常文件交接，下载前记录预期帧数，动作后核对真实落盘。一次只导出一个目标序列。已有验证过的本地包则不重复下载。
2. 以最终落盘的文件为准。网页可能逐层返回 ZIP，再合成为一个成品。网络监听只反映观测窗口内的请求，分包计数不能用于判断成品缺层。优先用浏览器受支持的下载事件拿到实际路径。若事件没返回文件，核对浏览器配置的下载位置或 Windows 实际下载目录。系统目录如果被迁移，`%USERPROFILE%\Downloads` 可能仍存在而没有新文件。
3. 在 Windows 可用下面的只读命令解析当前用户的实际 Downloads。若浏览器对下载位置另有自定义，以浏览器实际返回的位置为准。限于本次操作的时间和文件类型找候选，核对序列身份、独立网页帧数、实际解码和物理位置。浏览器重复生成的完整 ZIP 即使包封不同，里面也可能是同一批 DICOM。比较解压成员内容，确认重复时只保留一份用于处理。
4. 监听事件可能阻塞点击时，直接完成正常网页操作后验证成品，勿长时间等待同一个挂起事件。零散 ZIP 可以归集到任务专用目录，用离线脚本逐包清点。只有核对实际保存位置后仍无完整成品，才标注交接受阻。不要输出原始请求参数或以浏览器缓存、第三方下载站替代医院的正常导出。

```powershell
$myfilmDownloadGuid = '{374DE290-123F-4565-9164-39C4925E467B}'
$myfilmFolderSettings = 'HKCU:/Software/Microsoft/Windows/CurrentVersion/Explorer/User Shell Folders'
$myfilmDownloadValue = (Get-ItemProperty -LiteralPath $myfilmFolderSettings).$myfilmDownloadGuid
if ($myfilmDownloadValue) {
    [Environment]::ExpandEnvironmentVariables($myfilmDownloadValue)
}
```
