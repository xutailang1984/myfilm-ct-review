# MyFilm 云胶片和 CT 复核

需要可运行 Python 3.10+ 并能访问本地文件的助理。网页取片还需 Playwright、受支持的 Chromium 浏览器和 MyFilm 网络连接，已验证 Windows 与 Chrome。

优先使用用户已授权且已有的本地原始 DICOM。首次获取或补取 MyFilm 原片，先按 [自动验证、选片和导出](references/myfilm-automation.md) 使用 `scripts/myfilm_fetch.py`。目标是左膝、右膝或腰椎时优先按部位选片，无需预先知道序列号。只在用户已有明确的骨性或软组织复核目标时加相应重建偏好。若符合部位的原始重建不唯一、元数据有冲突或仍有无法排除的候选，给出区别和缺失证据。脚本使用隔离浏览器完成正常网页交互，无需 Computer Use。对未支持的部位、页面变动或报告核对使用 [网页调阅与导出](references/myfilm-web.md)。分享码仅用于原站验证界面。不要记录链接、凭据、UID、姓名、截图中的身份信息或将影像上传到别处。

已有本地 ZIP 或 DICOM 目录时直接按 [离线校验和测量](references/dicom-review.md) 使用 `scripts/ct_review.py`。先 `inventory`，再显式指定 `--group`。有可信的网页预期图像数时提供 `--expected-count`。输出放任务私有工作区。

把以下状态分别交代：

1. 网页报告、目标序列与实际像素是否可见。记录目标序列号、帧数，另核对部位、侧别、原生与衍生、重建核。
2. 原始文件是否实际交接。按钮存在、已点击、收到 ZIP 响应、磁盘有完整序列分别是不同的证据。缺失文件时保留网页阅片路径，请医院提供导出作为可选后备。
3. 几何是否通过、像素是否逐层解码、是否匹配独立计数。保留原始层标识的私下映射。网页截图不能当原始像素、HU 或毫米标定来源。
4. 确认测量对象后再量。保存两个端点、复核切面、方向和厚度，检查相邻原生层与另一垂直面。两点距离不自动代表骨片分离或关节面台阶，局部结果不等于全局最大。出现无法确认的解剖对应则报告缺口。

新片的工程演练可只验收调阅、序列选择、窗口切换、导出与几何，各项独立标结果。医疗诊断或治疗讨论另按用户所问开展，将影像观察、临床判据和查体缺口分开。
